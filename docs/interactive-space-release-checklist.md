# 互动空间发布清单

本项目只有一条完整产品代码线。互动空间包必须由 `npm run build:interactive` 生成，不能手工压缩普通网页构建产物。

## 构建与合规

1. 互动空间运行时必须完整包含全部 100 个历史开局、对应固定首幕与本地历史图，不保留三剧本审核子集。
2. 根目录只有一个 `index.html`，全部文件名使用 ASCII，所有资源本地化并使用相对路径。
3. 不包含外链、网络请求、iframe、文件上传、原生弹窗、动态代码执行或 API 密钥。
4. AI 只能通过 `tt.callAIChatCompletion` 调用，模型固定为 `deepseek-v4-flash`。
5. 首页标题栏角落持续显示小型 `AI 生成` 标识，完整无障碍名称为“本作品包含人工智能生成内容”；成品事件与报告继续明确显示 `AI 生成 · V4 Flash` 或 `AI 辅助创作 · 固定开场`，互动空间包把“游戏说明”改成“体验说明”。
6. ZIP 必须不超过 8,388,608 字节，并同时通过仓库校验和官方 `h5-validator` 的目录、ZIP 两轮校验。

## 上传前

1. 使用 `interactive-space.release.json` 中的 AppID、竖屏方向与包类型。
2. 平台账号必须已经配置可用的火山引擎 API 密钥；密钥只由平台保存，绝不写进源码、配置、日志或 ZIP。
3. 更新作品时必须传 `ai_enabled: true`，并勾选审核页面的 AI 选项。
4. 上传后先做机审和真机体验，至少走完四幕、每幕 Roll，并确认双报告结局。
5. 若 AI 调用返回 `20107` 或提示未配置 API 密钥，立即停止提审，先修复平台密钥配置，不能提交一个会在玩家端失败的包。

## 提审

确认 AI 选项、V4 Flash、完整 100 个开局、8MB 上限、官方校验、真机完整流程全部通过后，再提交审核。当前线上旧包曾因“涉及违反法律法规”被拒，必须更新为本次完整合规包后重新送审，不能直接重提旧版本。
