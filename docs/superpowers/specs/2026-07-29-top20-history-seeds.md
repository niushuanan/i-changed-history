## 中国史（12 枚）

### 1. 长平之战 `changping-260bc`

| 字段 | 内容 |
|------|------|
| 角色 | 赵括中军掌管突围军令的校尉 |
| 决策 | 是否拒绝全军出垒并命廉颇旧部守住粮道 |
| 危机 | 白起的伏兵将在半个时辰后合围 |

**入选理由**：战国最著名的决战，家喻户晓。校尉掌管军令传递，完全可以拒绝传达赵括的出击命令——这是下级军官在职权范围内的抗命，而非越级替主帅做决策。危机（伏兵合围）与决策（是否出击）同属战场指挥域，逻辑链条完整。

### 2. 大泽乡起义 `daze-uprising-209bc`

|------|------|

| 危机 | 秦吏将在天亮后清点误期人员 |

**入选理由**：秦末标志性事件，人人耳熟能详。屯长是戍卒小队直接长官，可以现场发动起义。危机（误期被秦吏追究）与决策（起义求生）因果关系直接，玩家无需理解制度背景就能感受到紧迫。

**入选理由**：三国最著名的战役，认知度无须多言。军需官掌管火船释放时机，完全可以决定提前或推迟。危机（风力和暴露风险）与决策（何时放火船）同属战术执行域，且决策后果直接影响赤壁之战胜负，因果可传播性高。

### 5. 淝水之战 `feishui-383`

| 字段 | 内容 |
|------|------|
| 角色 | 苻坚中军传令官 |
| 决策 | 是否传达全军后退让晋军渡水的命令 |
| 危机 | 晋军渡河前的一刻钟 |

**入选理由**：以少胜多的经典战例。传令官可以延迟传达、歪曲传递甚至不传达命令——这是传令链条中一个小人物可以做的"手脚"。与斯大林剧本不同，他不是取消统帅的决策，而是在执行环节做调整，权力边界清晰。
