# Few-shot 示例重写：基于真实剧本的具体值替换

## 问题

`prompts.ts` 中 `turnContract().exactShapeExample` 有两个问题：

1. **actionSpec 和 instantEcho 的值是字段名占位符**（"谁"、"做什么"、"结果"、"代价"……）。模型学到的是"在这些字段里填字段名本身"，导致真实输出中出现 `"actor": "谁"` 这类无意义值。

2. **C（天外）牌写得像作业指标**。"让谎言化为黑烟"和"借来明日记忆"的问题是：它们看起来有想象力，但玩家看了不会想选——经不起"我为什么要在历史现场做这个"的追问。牌桌需要的 C 牌是让玩家觉得"这什么鬼？试试！"的操作。

## 根因分析

原作者拿到的要求是"C 牌要有想象力"，但没有绑定到具体的、有血有肉的历史现场上去想。结果是脱离上下文编设定——相当于在真空中设计超能力，而不是"一个在具体历史困境里的人，迫于形势出了一个猎奇的牌"。

更深层的问题：`exactShapeExample` 只展示结构，不展示"推理过程"。模型看到的是一个脱节的抽象示例，学不到"好牌长什么样"。

## 设计原则

1. **基于实际剧本**：few-shot 的场景必须来自真实的游戏 seed，不能凭空编造
2. **具体值代替占位符**：actionSpec/instantEcho 的每个值都必须像"一个人在现场说出的具体主意"，而不是字段再定义
3. **C 牌要有被选中的理由**：有趣、意外、让人想看看选了会怎样——不是"合理"，也不是"奇幻"
4. **跨风格覆盖**：选两个差异足够大的 seed（中国军事 × 世界航海），让模型看到不同场景下六张牌怎么写

## C 牌设计思路

这次 C 牌的共同特征：**操作是常识级的，但思路不是**。

- **给叛军送戏班子**：送戏班是正常犒军行为，暗号传情报是间谍行为，但把两者结合的思路是反常的。有趣来自"用文艺演出搞军事情报"的荒诞错位。
- **放斥候大假三日**：常规操作是加强侦察。反向操作（停止一切侦察）制造信息真空，反而让对方不敢动。有趣来自"反直觉比正直觉有效"的逻辑悖论。
- **拿指南针抵债**：指南针是真实的时代科技优势，用它来抵债是一种跨文明的价值置换。有趣来自"用一件航海家眼中的珍宝换一件水手眼中的赃物"。
- **改信泰诺宗教**：当场宣布全船人改信本地神。这不是什么策略，这是用最极致的方式说"我们是认真的"。有趣来自哥伦布那张脸——以及后续所有欧洲记载都会写"船长疯了"。

这些牌不需要违反物理规律，只需要违反"这个场景下正常人会怎么做"的预期。

## 代码改动

### `src/game/prompts.ts`

`exactShapeExample` 中：

- 场景级字段（headline、narrative、location、role、timePressure、causalBridge、worldStateChange、divergenceProof、historicalAnchors）保持通用描述

- causalLedger 和 visualTone 保持通用值

- rules 文本中的写作指引
- 其他使用 exactShapeExample 的调用方
- schema 验证逻辑
