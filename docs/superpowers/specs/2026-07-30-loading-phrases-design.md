# 生成页面趣味短语设计

## 设计目标

在 AI 生成历史剧本的等待过程中，用随机刷新的趣味短语降低玩家的枯燥感。借鉴 Claude Code spinner verbs 的思路，但去掉了旋转动词的形式限制，改为多组风格各异的中文短句。

## 为什么需要这个机制

当前生成页面的多处等待文本是固定的。玩家在生成过程中长时间盯着同一句话，容易产生等待焦虑。多组随机短语让每次生成的等待体验都有一丝新鲜感。

## 修改位置

共三处，都在 `src/screens/GeneratingScreen.tsx`。

### 位置 1：`developing-note` 底部氛围短语

**元素**：`<p className="developing-note">`

**当前文本**：`新的历史现场即将出现`

**出现条件**：AI 尚未返回任何内容时，底部显示的那行小字。

**替换方式**：从氛围短语池中随机取一条。

**短语池**（17 条，三种风格混合）：

**历史现场感**——翻阅泛黄的档案、追踪历史的蛛丝马迹、重新编织因果线、在故纸堆里寻找真相、擦拭旧时代的灰尘、校准时间线的刻度

**调皮/打破第四面墙**——历史学家还在翻书，别急、正在给时间线打结、平行宇宙正在加载中…、蝴蝶效应计算中，请勿扇动翅膀、时间机器正在预热、刚才的历史还没写好，再等等

**诗意/哲思**——历史不会等待、每一个决定都在重塑世界线、过去从未真正过去、历史没有草稿、时间是一条咬住自己尾巴的蛇

### 位置 2：`developing-draft` 草稿区校验短语（带切换动效）

**元素**：`<em>`（位于 `developing-draft` 节内）

**当前文本**：`场景仍在写成，完整校验后才能决定`

**出现条件**：AI 已有部分内容（headline + narrative）流回但生成未完成时，草稿区底部的 `<em>` 提示。

**替换方式**：从校验短语池中依次循环切换，每 1 秒切换一条。切换时带淡入动效。

**短语池**（7 条）：正在打磨最后的细节、推敲每一处遣词造句、校验历史事实的准确性、润色即将呈现的现场、调整叙事的时间线、核对所有历史细节、把碎片拼成完整画面

> 注意：位置 2 的语境是"已有内容流出，正在完善剩余部分"，短语需围绕"打磨/校验/润色"展开，不能使用与位置 1 相同的氛围型短语。循环切换让玩家感觉 AI 确实在处理不同步骤，而不是重复同一件事。

### 位置 3：`developing-steps` 三个进度步骤

**元素**：`<ol className="developing-steps">` 内的三个 `<li>`

**当前文本**：`确认真实人物与地点` → `把既有决定写进现场` → `写出下一次关键抉择`

**出现条件**：生成阶段的三个步骤列表。

**替换方式**：三个步骤各自独立从对应短语池中随机取一条，共 4 × 4 × 4 = 64 种组合。

**步骤 1 短语池**（4 条）：确认真实人物与地点、锁定历史坐标与人物、查明何时何地何人何事、确认时代与舞台

**步骤 2 短语池**（4 条）：把既有决定写进现场、将前序选择织入当下、让选择落地为具体场景、把前因铺成现场

**步骤 3 短语池**（4 条）：写出下一次关键抉择、推演下一个岔路口、标记下一个抉择点、为下一步埋下伏笔

## 数据模型

```
src/data/generatingPhrases.ts
  ├── ATMOSPHERE_PHRASES  → 用于位置 1 底部氛围（17 条）
  ├── POLISHING_PHRASES   → 用于位置 2 循环切换（7 条）
  ├── STEP1_PHRASES       → 用于位置 3 步骤 1（4 条）
  ├── STEP2_PHRASES       → 用于位置 3 步骤 2（4 条）
  └── STEP3_PHRASES       → 用于位置 3 步骤 3（4 条）
```

## 切换动效

位置 2 的短语每秒切换一次，用 CSS keyframes + DOM 重建实现：

```css
@keyframes phrase-fade-in {
  from { opacity: 0.3; transform: translateY(2px); }
  to   { opacity: 1; transform: translateY(0); }
}
```

React 侧以当前索引为 `<em>` 的 `key` 值，每次索引变化时 React 销毁旧元素重建新元素，动画自动重新触发。

## 边界情况

| 场景 | 行为 |
|------|------|
| 连续多次进入生成页 | 每次 mount 独立随机取氛围短语和步骤序列 |
| 草稿阶段持续较长 | 校验短语持续循环，每 1 秒切换一条 |
| 生成完成（ready） | 草稿区 `<em>` 消失，循环停止（组件 unmount 清除 interval） |
| 短语数组为空 | `as const` 编译期保证非空；代码层用 `??` fallback 回默认文本 |
